# ياقوت ERP — تطبيق iOS وiPadOS (Swift 6 + SwiftUI + Liquid Glass)

تطبيق Apple أصلي لمكتب سفيان للموبايل. يعمل على نفس خادم ياقوت ونفس قاعدة بيانات Supabase والصلاحيات، مثل الويب والأندرويد.

- **التقنيات:** Swift 6 (عزل افتراضي على MainActor وتزامن صارم) وSwiftUI.
- **الحد الأدنى:** iOS 26.
- **التصميم:** Liquid Glass الأصلي من Apple: ‏`glassEffect` و`GlassEffectContainer` و`glassEffectID` و`glassEffectTransition` و`glassEffectUnion`، و`.buttonStyle(.glass / .glassProminent)`.
- **التنقل:** ‏`TabView` بنمط `sidebarAdaptable`، و`Tab(role: .search)`، و`tabBarMinimizeBehavior`.
- **لا يوجد:** Flutter، ولا React Native، ولا blur أو glassmorphism مصطنع.

## الدخول والأمان
1. **حساب المحل:** مرة واحدة على الجهاز. يُحفظ مفتاح التفعيل في Keychain (`ThisDeviceOnly`). كلمة المرور لا تُحفظ.
2. **رمز PIN:** يحدد الموظف وصلاحياته من `employee_permissions`.
3. **Face ID / Touch ID:** اختياري. الرمز يُحفظ محمياً بالبصمة (`biometryCurrentSet`)، ويُتحقق منه على الخادم قبل الحفظ وفي كل فتح.
4. **القفل التلقائي:** بعد 5 أو 10 أو 15 أو 30 دقيقة خمول، وعند العودة من الخلفية.
5. **الأمان من جهة الخادم:** Service Role Key لا يصل للتطبيق. كل قراءة وكتابة تمر عبر دوال قاعدة البيانات نفسها.

## الأقسام
تظهر حسب الصلاحيات، والخادم يرفض أي طلب خارجها.

| القسم | المحتوى |
|---|---|
| الرئيسية | مؤشرات زجاجية، مخطط 7 أيام (Swift Charts)، «تحتاج انتباهك»، آخر الفواتير، وزر إجراءات سريعة يتحول (morph) |
| المبيعات والفواتير | قائمة على الآيفون. على الآيباد: **جدول قابل للفرز** مع تفاصيل جانبية، وفتح الفاتورة في **نافذة مستقلة** |
| الزبائن والديون | كشف حساب، إضافة دين، تسديد ومسامحة، زبون جديد مع كشف تكرار الهاتف، واتساب واتصال، تصدير CSV، سحب وإفلات، عمودان على الآيباد |
| الخزنة والمصروفات | إيداع وسحب ومصروف جديد، مع **تأكيد صريح** قبل التنفيذ |
| المخزون والنواقص | جدول قابل للفرز على الآيباد |
| المشتريات والموردون | قراءة فقط، عبر دوال قسم الشراء |
| الصيانة والمرتجعات والشحن | نقل حالة الصيانة وإبلاغ الزبون |
| إدارة الإنترنت (ISP) | ملف مشترك موحّد يفصل بيانات المزوّد عن الزبون الداخلي، تذكير بالتجديد، ولوحات NBTEL وEarthlink |
| أجهزة الشبكة | MikroTik وUISP — انظر [INTEGRATIONS.md](INTEGRATIONS.md) |
| استيراد الكشوفات | PDF نصي أو ممسوح (OCR)، xlsx، CSV، صور، مسح بالكاميرا، مع معاينة ومنع تكرار |
| الموظفون والجلسات وسجل العمليات | — |
| التقارير | مخططات وتصدير |
| الإشعارات | الصندوق، وإدارة إشعارات الموظفين، والإشعار المخصص |
| الإعدادات | الإشعارات، Face ID، القفل، المظهر |
| البحث الشامل | زبائن، فواتير، منتجات، مشتركون، أقسام |

**تجربة الآيفون:** شريط تبويب زجاجي يصغر عند التمرير (الرئيسية، المبيعات، الديون، الإنترنت، المزيد)، وتبويب بحث، واختصارات من أيقونة التطبيق.

**تجربة الآيباد:**
- شريط جانبي بمجموعات الأقسام، وأعمدة متعددة، وجداول قابلة للفرز.
- عدة نوافذ (فاتورة، كشف حساب)، وسحب وإفلات للملفات في الاستيراد.
- اختصارات لوحة المفاتيح:
  - ⌘1 إلى ⌘9 للأقسام.
  - ⌘F للبحث، ⌘R للتحديث، ⌘N لعملية جديدة، ⇧⌘L للقفل.

**الإمكانية:** RTL، وDynamic Type، و«تقليل الحركة» (تتوقف الخلفية المتحركة ورسوم الترحيب)، والوضع الفاتح والداكن، وتسميات VoiceOver.

## البناء (GitHub Actions على macOS)
لا يحتاج جهاز Mac محلي. ملف [`.github/workflows/ios.yml`](../.github/workflows/ios.yml) يعمل على `macos-26` بالخطوات التالية:
1. توليد مشروع Xcode بـ XcodeGen من `project.yml`.
2. بناء التطبيق وتشغيل الاختبارات على محاكي iPhone ثم iPad.
3. تشغيل التطبيق على المحاكيين وأخذ لقطات شاشة.
4. أرشفة نسخة الجهاز وإنتاج `Yaqoot-ERP-unsigned.ipa`.
5. **إن وُجدت أسرار التوقيع:** توقيع وتصدير `Yaqoot-ERP.ipa` (Ad Hoc) والتحقق من التوقيع.

**الأسرار في GitHub** (Settings ← Secrets and variables ← Actions):

| السر | المحتوى |
|---|---|
| `YQ_BASE_URL` | رابط خادم ياقوت `https://…` (لا يُحفظ في Git) |
| `IOS_CERT_P12_BASE64` | شهادة **Apple Distribution** بصيغة ‎`.p12` مرمّزة base64 |
| `IOS_CERT_PASSWORD` | كلمة مرور ملف ‎`.p12` |
| `IOS_PROFILE_BASE64` | ملف تعريف **Ad Hoc** للتطبيق `iq.yaqoot.erp` يحوي UDID أجهزتك، مرمّزاً base64 |
| `IOS_TEAM_ID` | Team ID من حساب Apple Developer |

**محلياً على Mac (اختياري):**

```sh
brew install xcodegen
cd ios-app && xcodegen generate && open YaqootERP.xcodeproj
```
