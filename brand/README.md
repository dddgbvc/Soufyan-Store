## فكرة الشعار

الرمز هو حرف **«س»** من «سفيان» بعد حذف طرفه الأيسر الصاعد، فتبقى ثلاثة
أعمدة متدرّجة الارتفاع على قاعدة مفتوحة — تُقرأ في اللحظة نفسها كإشارة
شبكة خلوية. حرفٌ من الاسم ودلالةٌ على مجال العمل في شكل واحد.

## إعادة التوليد

```bash
cd brand
python3 tools/build_logo.py     # يولّد ملفات الشعار SVG
python3 tools/build_neon.py     # يولّد لوحة الواجهة المضيئة
node    tools/render.js --all   # يصدّر كل الألواح صوراً PNG
python3 tools/build_dist.py     # يبني نسخة HTML مستقلة لكل مجموعة
python3 tools/build_pdf.py      # يجهّز ملفات المطبعة PDF
```

للمطبوعات (ستيكرات، بطاقة عمل، وصل صيانة، ملصقات باركود) استخدم `--scale 2`
لتصل الدقة إلى 300 نقطة/إنش:

```bash
node tools/render.js pages/06-stickers.html pages/08-business-card.html \
                     pages/09-service-ticket.html pages/11-barcode-label.html \
                     pages/14-invoice.html --scale 2
```

`tools/textpath.py` هو ما يحوّل النص العربي إلى مسارات متجهة: يستخدم
HarfBuzz لتشكيل الحروف ووصلها بشكل صحيح، ثم fontTools لاستخراج حدود
كل حرف.

## أدوات المحل داخل البرنامج

أُضيفت لوحة داخلية إلى `index.html` تفتحها من زر 🧰 في الهيدر، فيها ثلاثة تبويبات:

**وصل الصيانة** — نموذج فيه اسم الزبون، رقم الهاتف، نوع الجهاز، رقم الجهاز IMEI،
رمز القفل، الملحقات، نوع الخلل (خانات متعددة الاختيار)، وصف الخلل، التواريخ،
والكلفة. يطبع:

- **وصل A5** بنسختين — نسخة المحل ونسخة الزبون مفصولتان بخط قص
- **ستيكر الجهاز 90 × 50 مم** يُلصق على الهاتف
- **وصل حراري 80 مم** — نسخة الزبون على رول الطابعة الحرارية، فيها كل بياناته
  والمتبقّي يُحسَب تلقائيًا. أسود على أبيض فقط لأن الطابعة أحادية اللون.

رقم الوصل يُولَّد تسلسليًا (`SFN-00001`) ويُطبع كباركود. الوصولات تُحفظ في
`localStorage` مع بحث بالرقم أو الاسم أو الهاتف، وإعادة طباعة لأي وصل سابق.

**فاتورة البيع** — الزبون وهاتفه، وأسطر المواد (اسم · كمية · سعر · IMEI
للأجهزة)، والخصم والمدفوع وطريقة الدفع والبائع والملاحظات. المجاميع تُحسَب
لحظيًا أمامك، وتُطبع:

- **فاتورة حرارية 80 مم** — نفس طابعة وصل الصيانة
- **فاتورة A5** ملوّنة بجدول مواد وتوقيع المستلِم — للمبيعات الكبيرة والجملة

رقمها تسلسل مستقل (`SFN-INV-00001`) حتى لا تختلط بمراجعة وصولات الصيانة،
والفواتير تُحفظ وتُبحث وتُعاد طباعتها مثل الوصولات.

**ملصقات الباركود** — نوعان:

- **ملصق الهاتف 75 × 50 مم** — الاسم والسعر، ثم النموذج والـIMEI والذاكرة
  واللون وصحة البطارية والحالة والأعطال والملاحظات، ثم الباركود.
- **ملصق الإكسسوارات 50 × 30 مم** — المقاس المعتمد كما هو: الاسم والسعر
  والباركود فقط، بلا حقول جهاز.

المقاسات الأربعة (75×50 · 60×40 · 50×30 · 40×25 مم) متاحة لأي نوع، واختيار
النوع يضبط المقاس المعتمد له تلقائيًا. معاينة حيّة، وطباعة شيت A4 بأي عدد
نسخ أو ملصق مفرد بمقاس الرول. أرقام المنتجات تُولَّد تلقائيًا بالبادئات
`SFN-PH` و`SFN-AC` و`SFN-NT`.

### الباركود

`tools/code128.js` مولّد **Code 128** مكتوب من الصفر بلا مكتبات خارجية،
يختار النمط C تلقائيًا للأرقام الزوجية (ضِعف الكثافة) والنمط B لغيرها.
النسخة نفسها مدمجة داخل `index.html`. مُتحقَّق من صحّة مجموع التدقيق مقابل
القيم المنشورة (`CODE128` → 26).

> اللوحة الداخلية مخفية افتراضيًا ويكشفها زر في الهيدر — هذا ترتيب واجهة
> لا حماية أمنية؛ من يفتح الصفحة يقدر يظهرها.

## الحزمة البرمجية `ts/`

نفس المطبوعات مكتوبة TypeScript بأنواع كاملة، لأي مشروع لاحق (تطبيق جوال،
واجهة إدارة، خادم يولّد PDF):

```ts
import { invoiceThermal80, printDocument, invoiceNo, today } from './brand/ts/src';

printDocument(invoiceThermal80({
  no: invoiceNo(318), customer: 'أحمد عبد الله', date: today(),
  items: [{ name: 'Samsung Galaxy A54', qty: 1, price: 385_000, imei: '356938035643809' }],
  discount: 10_000, payment: 'نقدًا',
}));
```

كل دالة تُعيد `PrintableDoc` (جسم HTML + قواعد CSS بالمليمتر) ولا تطبع
بنفسها — تقدر تطبعها أو تحفظها أو تمرّرها لمولّد PDF. تفاصيلها في
[`ts/README.md`](ts/README.md).

## ملاحظات مراجعة

جرى تصحيح خمس مشاكل بعد المراجعة:

1. **`viewBox` خاطئ في كل ملفات الشعار** — كان المولّد يكتب ستة أرقام بدل
   أربعة (`viewBox="0 0 44 58 152 124"`)، فكان ملفّا الرمز المستقل يظهران
   مقصوصين. صار المولّد يمرّر الإطار كاملًا.
2. **قص طرف الرمز** — كان إطار الرمز ملاصقًا لحدود الخط تمامًا، فتُقصّ نهاية
   القاعدة المستديرة من اليسار وتحت. صار الإطار يترك 4 وحدات هامش.
3. **خط أسود في الشعار داخل كانفا** — `fill:none` كان في CSS على عنصر
   `<svg>`، ومحوّل كانفا لا يورّثه للمسارات، فيملأ منحنى القاعدة بالأسود.
   صارت `fill="none"` خاصية عرض على كل مسار.
4. **دقة التصدير** — `render.js` كان يمرّر `scale:'css'` فيتجاهل مضاعف الدقة،
   وتُصدَّر ملفات الطباعة بـ150 نقطة/إنش بينما السجل يقول 300.
5. **انقلاب ترتيب رقمَي الهاتف** — كان كل رقم معزولًا وحده داخل تدفّق RTL،
   فيظهر الرقم الثاني أولًا. صار الزوج داخل حاوية LTR واحدة، وكذلك صفوف
   المواصفات اللاتينية.
