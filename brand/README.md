# مكتب سفيان للموبايل — الهوية البصرية

هوية بصرية كاملة: الشعار، نظام الألوان والخطوط، بوستات وستوري وأغلفة،
أغلفة هايلايت، ستيكرات، وتصاميم كيس التسوق وعلبة المنتج.

**الشعار اللفظي:** شاشتك الجاية تبدأ من هنا
**العنوان:** سامراء — الحويش — الشارع الرئيسي · **واتساب:** 0773 164 4450 · 0774 448 5771

---

## فكرة الشعار

الرمز هو حرف **«س»** من «سفيان» بعد حذف طرفه الأيسر الصاعد، فتبقى ثلاثة
أعمدة متدرّجة الارتفاع على قاعدة مفتوحة — تُقرأ في اللحظة نفسها كإشارة
شبكة خلوية. حرفٌ من الاسم ودلالةٌ على مجال العمل في شكل واحد.

النسبة المقترحة: **60% رملي · 30% بترولي · 10% ذهبي**.

## الخطوط

- **El Messiri** — العناوين واسم العلامة في الشعار
- **Cairo** — المتن والأرقام والأسعار

كلاهما مجاني من Google Fonts، ونسخة الويب منهما داخل `fonts/`.

## محتويات المجلد

```
brand/
├── logo/       ملفات الشعار SVG — متجهة بالكامل، بلا خطوط حيّة
├── png/        كل الألواح مصدَّرة صوراً جاهزة للنشر
├── pdf/        ملفات جاهزة للمطبعة
├── dist/       نسخة HTML مستقلة من كل مجموعة (للاستيراد إلى كانفا)
├── pages/      ملفات التصميم المصدرية
├── css/        نظام التصميم — الألوان والخطوط والعناصر المشتركة
├── fonts/      الخطوط بصيغة woff2
└── tools/      أدوات التوليد والتصدير
```

### ملفات الشعار

| الملف | الاستخدام |
|---|---|
| `logo-primary.svg` | الصيغة الرئيسية (عمودية) على خلفية فاتحة |
| `logo-primary-onDark.svg` | الصيغة الرئيسية على خلفية داكنة |
| `logo-horizontal.svg` / `-onDark.svg` | الصيغة الأفقية للأغلفة والترويسات |
| `logo-icon.svg` / `logo-icon-light.svg` | الأيقونة — صورة الحساب |
| `logo-mark.svg` / `logo-mark-sand.svg` | الرمز وحده بخلفية شفافة |
| `logo-stamp.svg` | الختم الدائري للستيكرات والتغليف |
| `logo-mono.svg` | نسخة أحادية اللون للطباعة بلون واحد |

جميعها **مسارات متجهة** (Outlines) — تُفتح في كانفا أو عند المطبعة
دون الحاجة لتنصيب أي خط.

## إعادة التوليد

```bash
cd brand
python3 tools/build_logo.py     # يولّد ملفات الشعار SVG
node    tools/render.js --all   # يصدّر كل الألواح صوراً PNG
python3 tools/build_dist.py     # يبني نسخة HTML مستقلة لكل مجموعة
python3 tools/build_pdf.py      # يجهّز ملفات المطبعة PDF
```

`tools/textpath.py` هو ما يحوّل النص العربي إلى مسارات متجهة: يستخدم
HarfBuzz لتشكيل الحروف ووصلها بشكل صحيح، ثم fontTools لاستخراج حدود
كل حرف.

## ملاحظات للاستخدام

- الحقول مثل «اسم الهاتف هنا» و«000,000 د.ع» حقول تُملأ عند كل منشور.
- الخطوط المتقطّعة في شيت الستيكرات ومخطط القص **أدلّة ولا تُطبع**.
- قيم CMYK في الدليل تقريبية لورق مطلي — راجعها مع المطبعة قبل السحب.
