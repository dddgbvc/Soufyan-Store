# الهوية البصرية — مكتب سفيان للموبايل

كل شيء مبنيّ بـ **HTML + SVG** — فيكتور، قابل للتكبير بلا حدود، ونصوصه تتعدّل بالكتابة.
لا صور مسطّحة، ولا اعتماد على إنترنت: الخطوط والرمز والباركود والـQR كلها داخل المجلد.

| افتح | تشوف |
|---|---|
| `kit.html` | **الهوية الكاملة** — 23 لوح تصميم |
| `logo.html` | الشعار — 6 صيغ + المواصفات |
| `../print/index.html` | المطبوعات — ستيكرات ووصولات حرارية |

---

## الشعار

الرمز حرف **«س»** من «سفيان» بعد حذف طرفه الأيسر، فتبقى أعمدته الثلاثة متدرّجة
الارتفاع كإشارة الشبكة الخلوية.

| | قبل | بعد |
|---|---|---|
| القاعدة الأفقية | موجودة | **محذوفة** |
| سمك الأعمدة (من 100) | ~13.5 | **16.5** |
| الخط | El Messiri | **ثمانية Sans** |

**هندسة الرمز — شبكة 100:** سمك العمود `16.5` · الفجوة `8.5` · الارتفاعات `30 · 44 · 58`
(متصاعدة نحو اليمين) · نهايات نصف دائرية `rx = 8.25` · **لا قاعدة**.

## الخط

مجاني للاستخدام الشخصي والتجاري · <https://font.thmanyah.com/>

## التعديل

كل النصوص والبيانات في مكان واحد أعلى `kit.js`:

```js
var SHOP = { name, latin, tagline, address, phone1, phone2, net, hours, wa };
```

وكل لوح دالة مستقلة داخل `A["اسم-اللوح"]`. غيّر النص، أعد فتح الصفحة — خلص.

```js
SufyanKit.html("post-2")           // نص HTML للوح
SufyanKit.ARTBOARDS["fb-cover"]    // { w, h, label }
SufyanKit.mark(bars, accent)       // الرمز بأي لونين
SufyanKit.icon("whatsapp")         // أيقونة خطية
```

## ملاحظات مهمّة

**كيس التسوق** — التصميم لـ **نسيج غير منسوج (Non-woven)** مو كارتون: يُطبع
سلك-سكرين بلونين (رملي + ذهبي) على قماش بترولي، أو طباعة حرارية كاملة.
الحبل بنفس القماش. المقاس 32 × 40 سم مع جوانب 12 سم.

**الملصق القابل للكسر** — التصميم لوحده ما يكفي، الخاصية بالورق:
اطلبه **Eggshell** أو **VOID Polyester**. الورق العادي يُنزع سليماً ويفقد فائدته.

**QR الواتساب** — `qr-whatsapp.svg` مولّد فعلياً ومتحقَّق منه (يفكّ إلى
`https://wa.me/9647731644450`). إذا تغيّر الرقم لازم يُعاد توليده.

**أغلفة الهايلايت** — إنستغرام يقصّها **دائرة من وسط** الصورة 1080×1920،
لذلك الأيقونة والاسم داخل دائرة آمنة بالمنتصف.

**غلاف فيسبوك** — يُقصّ من الأطراف على الموبايل، فالنص كله داخل الثلث الأوسط.
