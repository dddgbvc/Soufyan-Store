# الشعار — مكتب سفيان للموبايل

الشعار مُعاد بناؤه بالكامل بـ HTML + SVG (فيكتور، قابل للتكبير بلا حدود).

## التغيير عن النسخة السابقة

| | قبل | بعد |
|---|---|---|
| القاعدة الأفقية لحرف «س» | موجودة | **محذوفة** |
| سمك الأعمدة (من أصل 100) | ~13.5 | **16.5** |
| الخط | El Messiri | **ثمانية Sans** |

دليل الهوية يصف الرمز بأنه «حرف «س» من سفيان بعد حذف طرفه الأيسر — فتصبح أعمدته
الثلاثة متدرّجة الارتفاع كإشارة الشبكة الخلوية». الرسم السابق كان لا يزال يحمل
القاعدة الأفقية؛ هذه النسخة تطابق النص.

## الملفات

| الملف | الاستخدام |
|---|---|
| `logo.html` | ورقة الشعار — كل الصيغ + المواصفات |
| `logo.css` | نظام الشعار: يُستورد في أي صفحة لاستخدام العلامة مباشرة |
| `mark.svg` | الرمز وحده — للخلفيات الفاتحة |
| `mark-on-dark.svg` | الرمز وحده — للخلفيات الداكنة |
| `favicon.svg` | أيقونة التبويب وصورة الحساب |
| `exports/*.png` | لقطات 1080×1080 لكل صيغة |
| `fonts/` | خط ثمانية Sans — الأوزان 300 · 400 · 500 · 700 · 900 |

## الاستخدام في صفحة

```html
<link rel="stylesheet" href="brand/logo.css">

<div class="sufyan-logo" style="--size:160px">
  <div class="sufyan-logo__plate"><!-- mark.svg هنا --></div>
  <div class="sufyan-logo__type">
    <div class="sufyan-logo__name">مكتب سفيان للموبايل</div>
    <div class="sufyan-logo__latin">SUFYAN MOBILE</div>
  </div>
</div>
```

`--size` يتحكم بالقياس كاملاً — كل شيء آخر محسوب منه.
الصيغ: `sufyan-logo--row` (أفقية) · `sufyan-logo--on-dark` · `sufyan-logo--mono`.

## هندسة الرمز — شبكة 100

- سمك العمود: `16.5` · الفجوة: `8.5`
- الارتفاعات: `30 · 44 · 58` (متصاعدة نحو اليمين)
- النهايات نصف دائرية (`rx = 8.25`) · **لا قاعدة أفقية**
