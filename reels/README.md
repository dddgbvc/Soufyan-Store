# ريلز مكتب سفيان للموبايل — النسخ المعدّلة

إعلان متحرك لـ **مكتب سفيان للموبايل** — سامراء، الحويش، الشارع الرئيسي.
أُعيد بناء الإعلان من الصفر (HTML + CSS مُحرَّك بجافاسكربت، ورندر إطار‑بإطار عبر Chromium)
حتى يمكن التحكم بالنص والانتقالات ومعدل الإطارات بدقّة.

المدة: **٢٥ ثانية** · الإيقاع: **١٢٠ BPM** · كل قطع مشهد يقع على ضربة موسيقية.

نسخة الـ 90fps مرندرة أصلًا بمعدلها.

## الصوت

موسيقى مُولَّدة بالكامل بالسكربت (`src/make_audio.py`) — **خالية من حقوق الملكية ١٠٠٪**،
ما بيها أي عيّنة مرخّصة. مقام شرقي (D حجاز) مع إيقاع ١٢٠ BPM:

- مقدمة هادئة، ثم دخول الإيقاع، ثم تخفيف عند مشهد «راحتك قبل البيعة»، ثم ختام.
- نقرة انتقال ناعمة (جرس) عند كل تغيير مشهد — مو صفّارة حادة.
- المستوى: **−13.7 LUFS** وذروة حقيقية **−1.1 dBTP** — مضبوط لمنصات التواصل.

## التعديلات المطلوبة وكيف نُفِّذت

**١ — أصوات مناسبة**
الفيديو الأصلي كان **بدون مسار صوتي إطلاقًا**. أُضيفت موسيقى مُولَّدة كما فوق.

**٢ — ثلاث نسخ بمعدلات إطارات ٦٠ و٩٠ و١٢٠**
ستة ملفات (ثلاث معدلات × مقاسين). كانفا ما يصدّر 90/120fps،
لذلك النسخ الأصلية موجودة هنا بجيت هب.

**٣ — بلا عبارات مستهلكة**
| قبل | بعد |
|---|---|
| كل شي لهاتفك بمكان واحد | هاتفك عدنا أمانة |
| أربع خدمات **تحت سقف واحد** | أربع خدمات… وما نخلّيك تدور |
| اتصل أو مرّ علينا | مرحبتين بيك… ننطرك |
| تعال شوفنا | تدخل ضيف… وتطلع مرتاح |

**٤ — عبارات تحسّس الزبون بأهميته**
أُضيف مشهد كامل عنوانه **«راحتك قبل البيعة»**:
- نسمع سؤالك للآخر — وننصحك حتى لو ما اشتريت
- تدخل باسمك، مو برقم بالدور
- بعد البيع، نفس الترحيب ونفس الباب

وكذلك في مشهد التعريف: «وسؤالك بعد البيع يلگه جواب».

**٥ — نظام الساعة ١٢**
كان: `يوميًا · 22:00 — 9:00` (نظام ٢٤، وكان يُقرأ معكوسًا بسبب اتجاه النص).
صار: **`يوميًا من 9:00 صباحًا إلى 10:00 مساءً`** — بلا التباس باتجاه القراءة.
(مطابق للدوام المذكور بـ `worker.js`: يوميًا ٩ص–١٠م.)

**٦ — بلا تنقلات مزعجة**
- كل الانتقالات ذوبان متقاطع ٠٫٧٥ ثانية — ما بيها قطع مفاجئ ولا ومضات ولا انزلاق سريع.
- منحنيات تسارع بدون ارتداد (`ease-out` بلا overshoot) — ما بيها شي «ينطّ».
- حركة الدخول ٢٠ بكسل عموديًا وتكبير ١٫٢٪ فقط — محسوسة بس ما تشتّت.
- الخلفية تتبدّل بذوبان تدريجي، مو قلبة لون مفاجئة.

## إعادة الإنتاج

```bash
cd reels/src
pip install numpy
python3 make_audio.py
ffmpeg -i build/soundtrack.wav -af "loudnorm=I=-14:TP=-1.5:LRA=11" -ar 48000 -ac 2 build/track.wav

node render.js r916 120   # يُخرج 120fps و 60fps معًا
node render.js r916 90
node render.js r11  120
node render.js r11  90
```

يتطلّب `ffmpeg` و Chromium عبر Playwright.
الخطوط من Google Fonts (Tajawal و IBM Plex Sans Arabic) — رخصة SIL OFL.
