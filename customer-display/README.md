# شاشة الزبون · Customer Display

شاشة عرض الفاتورة للزبون في نقطة البيع — **مكتب سفيان للاتصالات**.

واجهة عربية RTL بالكامل، وضع فاتح وداكن، مزامنة لحظية مع الكاشير، وجاهزة
للعمل على شاشة أفقية من 1280×720 حتى 4K.

---

## التشغيل السريع

وحدات JavaScript الحديثة لا تُحمَّل عبر `file://`، لذلك نحتاج خادمًا محليًا
(بلا أي تبعيات — المكتبة القياسية لبايثون تكفي):

```bash
python3 customer-display/serve.py
```

ثم افتح:

| الصفحة | الرابط |
| --- | --- |
| شاشة الزبون | <http://localhost:8080/customer-display/> |
| محاكي الكاشير | <http://localhost:8080/customer-display/cashier-demo.html> |

بدائل إن لم يتوفّر بايثون: `npx --yes serve .` أو `npx http-server .`

### أسرع طريقة لرؤية كل شيء يعمل

1. افتح **محاكي الكاشير**.
2. اضغط **«فتح شاشة الزبون»** — تُفتح في نافذة ثانية.
3. اضغط على أي منتج في الكتالوج: يظهر فورًا على شاشة الزبون.
4. غيّر الكمية، أضف خصمًا، ثم **بدء الدفع** ← **إتمام الدفع**.
5. اضغط **«تبديل المظهر»** في الكاشير: شاشة الزبون تتبعه في اللحظة نفسها.

### وضع تجريبي بنافذة واحدة

داخل شاشة الزبون اضغط **`D`** لفتح لوحة تحكّم تجريبية مخفية (أو افتح
`?demo=1`). تتيح: إضافة/حذف منتج، تغيير كمية، خصم، ضريبة، بدء الدفع،
إتمامه، تعليق، إلغاء، حالة خطأ، وتبديل المظهر.

للعرض التلقائي المتكرّر (شاشة معرض مثلًا): `?demo=auto`

## نظام التصميم

كل قيمة بصرية تمرّ من `styles/design-tokens.css` — لا ألوان أو ظلال مكتوبة
مباشرة في بقية الملفات.

| التوكن | فاتح | داكن |
| --- | --- | --- |
| `--color-background` | `#F7F5EF` أوف-وايت دافئ | `#101613` فحمي مائل للأخضر |
| `--color-surface` | `#FFFFFF` | `#182120` |
| `--color-primary` | `#0E5C42` زمردي عميق | `#2FB37F` زمردي |
| `--color-secondary` | `#D9A441` ذهبي ناعم | `#D9A441` |
| `--color-text` | `#16211C` | `#EDF2EF` |

كما تُعرَّف: `--radius-*` (8 → 40px، الأساس 18px)، `--shadow-*` (طبقات
شفافة ناعمة)، `--spacing-*` (قاعدة 4px)، `--text-*` (سلم يتجاوب مع حجم
الشاشة)، و`--ease-out: cubic-bezier(0.22, 1, 0.36, 1)`.

الوضع الداكن **ليس قلبًا للألوان**: الأسطح فحمية دافئة بميل أخضر خفيف بلا
أسود صافٍ، وبطاقة الإجمالي تتحوّل من كتلة زمردية مصمتة (فاتح) إلى سطح
زمردي داكن بحبر فاتح (داكن) — لأن كتلة لامعة ليلًا تُتعب العين.

### الطباعة

خط **Cairo** بأوزان 400/500/600/700، **مستضاف محليًا** في
`assets/fonts/` (~81KB لكل المقاطع). لا اعتماد على CDN: الشاشة تعمل حتى
مع انقطاع الإنترنت، ولا تتغيّر أشكال الأرقام فجأة.

كل الأرقام `tabular-nums`، فلا يهتزّ التخطيط أثناء تحديث المبالغ.
العملة تُعرض في عنصر منفصل عن الرقم (`flex`) لتفادي مفاجآت خوارزمية
الاتجاه ثنائية النص: النتيجة دائمًا `850,000 د.ع`.

## مزامنة السمة مع البرنامج الرئيسي

شاشة الزبون **لا تملك سمة خاصة بها**. تعكس ما يختاره البرنامج الرئيسي عبر
ثلاث قنوات تعمل معًا:

1. `localStorage["theme"]` — **نفس المفتاح ونفس القيم** (`light` / `dark` /
   `auto`) المستخدمة في واجهة المتجر `index.html`. حدث `storage` يصل لكل
   تبويب على نفس الأصل، فينعكس التبديل خلال أجزاء من الثانية.
2. `BroadcastChannel("yaqoot-theme")` — مزامنة فورية بين النوافذ.
3. `prefers-color-scheme` — عندما يكون الوضع `auto`.

النتيجة تُطبَّق على `<html data-theme="light|dark">` — نفس العقد المستخدم في
البرنامج الرئيسي، ولذلك **لم يلزم تعديل أي سطر في `index.html` الأصلي**.

سكربت صغير في `<head>` يطبّق السمة قبل أول رسم لمنع وميض المظهر الخاطئ،
وتُوقَف كل الانتقالات لإطار واحد عند التبديل حتى لا «تتلطّخ» الشاشة.

## الربط اللحظي

```
الكاشير ──▶ ناقل ──▶ transport.js ──▶ store ──▶ مكوّنات الواجهة
```

الرسائل (كاشير ← شاشة):

| النوع | المحتوى |
| --- | --- |
| `session` | لقطة كاملة للجلسة |
| `patch` | تحديث جزئي |
| `status` | تغيير حالة فقط |
| `ping` | نبضة |

والشاشة ترسل `hello` عند الإقلاع لتطلب لقطة حالية.

### المحوّلات الجاهزة

| الناقل | متى يُستخدم | التفعيل |
| --- | --- | --- |
| **BroadcastChannel** | الافتراضي. الكاشير والشاشة على الجهاز نفسه (شاشة ثانية) — بلا خادم إطلاقًا | تلقائي |
| **WebSocket** | خادم نقطة بيع عبر الشبكة، مع إعادة اتصال تصاعدية | `?transport=ws&ws=wss://...` |
| **Supabase Realtime** | إن انتقلتم إلى Supabase لاحقًا | املأ `CONFIG.transport.supabase` |

> المشروع الحالي لا يستخدم Supabase، لذلك محوّله **لا يُحمَّل ولا يتّصل
> بالإنترنت إطلاقًا** ما لم تُضبط `url` و`anonKey` بنفسك. لم يُغيَّر شيء في
> البنية الخلفية القائمة.

### الربط بنظام كاشير حقيقي

استبدل `js/demo/*` بنظامك، وابعث كائن الجلسة على القناة. لا شيء في
`js/ui/` يحتاج تعديلًا.

```js
const bus = new BroadcastChannel('yaqoot-pos');

bus.postMessage({
  protocol: 'yaqoot-pos/1',
  type: 'session',
  source: 'my-pos',
  at: Date.now(),
  payload: {
    status: 'browsing',          // idle · browsing · paying · paid · held · cancelled · error
    items: [
      {
        id: 'line-1',
        name: 'iPhone 16',
        variant: '128GB · أسود',
        qty: 1,
        unitPrice: 850000,
        lineDiscount: 0,
        imageUrl: 'https://…/iphone16.jpg',   // اختياري
      },
    ],
    discount: 20000,             // خصم على مستوى الفاتورة
    taxRate: null,               // null = الضريبة غير مفعّلة، أو رقم مثل 15
    paid: 0,
    invoiceNumber: '20260911-1471',
  },
});
```

الحقول الناقصة تأخذ قيمًا افتراضية بدل أن تكسر الشاشة، والأسماء بصيغة
`snake_case` مقبولة أيضًا (`unit_price`, `image_url`, `tax_rate`…) لتسهيل
الربط المباشر بصفوف قاعدة بيانات.

## حالات الشاشة

| الحالة | ما يراه الزبون |
| --- | --- |
| `loading` | جارٍ الاتصال بنقطة البيع |
| `idle` | **بانتظار عملية الشراء** — رسم إيصال ناعم |
| `browsing` | قائمة المنتجات + الملخّص + الإجمالي |
| `paying` | جاري إتمام عملية الدفع… |
| `paid` | ✓ تمت العملية بنجاح + رقم الفاتورة + الباقي |
| `held` | بانتظار إتمام الدفع + المبلغ المتبقي |
| `cancelled` | تم إلغاء العملية — هادئة وغير مخيفة |
| `error` | تعذّر عرض العملية (مع إعادة اتصال تلقائية) |

الانتقال بين الحالات `crossfade` فقط. لكل حالة **أيقونة ونص**، فلا شيء
يعتمد على اللون وحده.

بعد النجاح تعود الشاشة تلقائيًا إلى الانتظار (افتراضيًا بعد 15 ثانية،
و8 ثوانٍ بعد الإلغاء) — يُضبط في `CONFIG.behavior`.

## الإعدادات

كل شيء في `js/config.js`: اسم المتجر والفرع والشعار، رمز العملة، الضريبة،
الناقل، مفتاح السمة، وسلوك الشاشة.

يمكن التجاوز من الرابط دون تعديل ملفات:

| المعامل | المثال |
| --- | --- |
| `?theme=` | `light` · `dark` · `auto` |
| `?transport=` | `broadcast` · `ws` · `supabase` · `none` |
| `?ws=` | `wss://pos.example.com/display` |
| `?channel=` | اسم قناة مخصّص |
| `?store=` · `?branch=` | تجاوز اسم المتجر/الفرع |
| `?currency=` | رمز عملة آخر |
| `?demo=` | `1` لفتح اللوحة · `auto` لعرض تلقائي |

## الوصولية

- تباين يحقّق **WCAG AA** في الوضعين، مع سلّم `prefers-contrast: more`.
- كل حالة لها أيقونة + نص، لا اعتماد على اللون وحده.
- `aria-live` على الحالة وعلى الإجمالي.
- احترام كامل لـ `prefers-reduced-motion`: الرسوم تظهر مكتملة بلا تحريك،
  والأرقام تنتقل فورًا.
- وصف نصّي كامل لكل سطر منتج لقارئات الشاشة.

## النشر

المجلد ثابت بالكامل (بلا خطوة بناء). ارفعه كما هو مع بقية الموقع؛ يعمل على
`/customer-display/` مباشرة على Cloudflare Pages أو أي استضافة ثابتة.

على جهاز الكاشير: افتح الرابط في نافذة منفصلة على الشاشة الثانية واضغط
`F11` لملء الشاشة.
