# مكتب سفيان للاتصالات — موقع متكامل

موقع تعريفي ومتجر مصغّر لمكتب سفيان للاتصالات في سامراء، مبني بلغة بصرية
**Liquid Glass** من آبل ومحرّك حركة فيزيائي (نوابض حقيقية) مكتوب من الصفر
بدون أي مكتبة خارجية.

---

## التشغيل

افتح `index.html` بأي متصفح حديث — لا يحتاج خادمًا ولا تنصيبًا.
(للأفضل: Chrome أو Edge أو Safari بأحدث إصدار، حيث يظهر تأثير الانكسار الزجاجي كاملًا.)

للرفع على استضافة: ارفع محتويات المجلد كما هي إلى الجذر.
يعمل مباشرة على GitHub Pages أو Netlify أو Cloudflare Pages بدون أي خطوة بناء.

## ماذا يوجد في الموقع

| القسم | الوصف |
|---|---|
| شريط تنقّل عائم | زجاج سائل يتكثّف عند النزول ويختفي عند التمرير للأسفل، مع مؤشّر يتحرّك بنابض |
| البطل | عنوان يصعد سطرًا سطرًا، جهاز ثلاثي الأبعاد يميل مع المؤشّر، بطاقات تطفو ببارالاكس |
| الخدمات | ست بلاطات تفاعلية، كل واحدة تفتح إجراءً حقيقيًا (شحن رصيد، حجز صيانة، فلترة المتجر) |
| الباقات | مفتاح مقسّم شهري/سنوي بمؤشّر سائل، والأسعار تتبدّل فورًا |
| المتجر | بحث + تصنيفات + ترتيب، بطاقات بتأثير ميلان، ولوح تفاصيل كامل لكل منتج |
| مرشد الاختيار | يحدّد أفضل جهاز حسب الميزانية والأولويات |
| الآراء | شريط يُسحب بالإصبع مع قصور ذاتي وارتداد مطّاطي عند الحواف |
| الأسئلة الشائعة | أكورديون يفتح بارتفاع نابض |
| السلة | تُحفظ محليًا، وتُحوّل الطلب إلى رسالة واتساب جاهزة |

## محرّك الفيزياء (`js/spring.js`)

كل الحركات التفاعلية مدفوعة بنابض حقيقي وليس بمدّة زمنية ثابتة:

```js
var s = new Physics.Spring({ preset: "bouncy", onUpdate: v => el.style.opacity = v });
s.to(1);           // ينطلق نحو الهدف بصلابة/تخميد/كتلة
```

- تكامل أويلر شبه الضمني بخطوات ثابتة (1/240 ثانية) — لا يتأثر بمعدّل الإطارات.
- حلقة `requestAnimationFrame` واحدة لكل الحركات، تتوقف تلقائيًا عند السكون.
- `Physics.inertia` للانزلاق بعد رفع الإصبع مع تسليم السرعة إلى نابض عند الحدود.
- `Physics.rubberBand` بمعادلة iOS للمقاومة المطّاطية.
- الجاهزيات: `snappy`, `smooth`, `gentle`, `bouncy`, `wobbly`, `stiff`, `lazy`.

عند تفعيل **تقليل الحركة** في نظام المستخدم، تتحوّل كل النوابض إلى قفز فوري
وتتوقف الحركات الزخرفية — احترامًا لإعدادات إمكانية الوصول.

## تعديل المحتوى

كل شيء في `js/data.js`:

- `info` — الاسم، العنوان، الدوام، أرقام الهاتف والواتساب.
- `services` — الخدمات الستّ.
- `plans` — باقات الإنترنت (سعر شهري وسنوي).
- `topups` — الشبكات وفئات شحن الرصيد.
- `phones` / `accessories` — المنتجات (`stock: false` تعني نفد).
- `voices` / `faq` — الآراء والأسئلة.

الأسعار أرقام صرفة بالدينار العراقي، والتنسيق يتم تلقائيًا.

### تغيير الألوان

بدّل قيم `--accent` و `--grad-iris` في `css/tokens.css` — يتبعها كامل الموقع
(الأزرار، البريق، التوهّج، المؤشّرات).

## ملاحظات تقنية

- لا يوجد أي اعتماد على npm أو أدوات بناء؛ ملفات ثابتة فقط.
- الخطوط من Google Fonts (Alexandria + IBM Plex Sans Arabic + DM Mono)،
  ومع انقطاع الإنترنت ترجع لخطوط النظام تلقائيًا.
- تأثير الانكسار يستخدم `backdrop-filter` مع مرشّح إزاحة SVG؛ في المتصفحات
  التي لا تدعمه يظهر زجاج ضبابي عادي دون أي كسر في التصميم.
- الوضع النهاري/الليلي يُحفظ محليًا، والتبديل يستخدم View Transitions حين تتوفّر.
