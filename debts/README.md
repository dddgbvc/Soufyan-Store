# 📒 دفتر الديون — مركز سفيان للهواتف

نظام بسيط لإدارة ديون الزبائن، بنمط **Liquid Glass** وحركة نابضية.
يعمل **بدون إنترنت وبدون تنصيب**: افتح `index.html` بنقرة مزدوجة.

---

## التشغيل

1. فُكّ ضغط المجلد في أي مكان على الكومبيوتر.
2. انقر نقرًا مزدوجًا على **`index.html`**.
3. لو كان الدفتر فارغًا، اضغط **«تعبئة بيانات تجريبية»** للتجربة، أو **«شخص جديد»** للبدء فعليًا.

> يُفضّل **Chrome** أو **Edge** — لأنهما يعطيان أفضل نتيجة في الطباعة وحفظ PDF.

---

## الخيارات الخمسة

كل بطاقة تُفتح بالضغط عليها، وتظهر كل التفاصيل مع هذه الأزرار:

| # | الخيار | ماذا يفعل |
|---|--------|-----------|
| ١ | ➕ **إضافة دين** | يضيف مبلغًا على ذمّة الشخص، مع بيان اختياري وأزرار مبالغ سريعة |
| ٢ | 💵 **تسديد دين** | يسجّل دفعة. زر «كامل المبلغ» يملأ المتبقّي دفعة واحدة |
| ٣ | 🤝 **مساواة الأرقام** | مسامحة عن كامل المتبقّي — يصبح الرصيد صفرًا **والسجل يبقى محفوظًا** |
| ٤ | 🖨️ **طباعة** | قائمة تختار منها: كشف حساب أو وصل آخر حركة، بمقاس **A4** أو **80mm** |
| ٥ | 📄 **حفظ PDF** | نفس القائمة — اختر «حفظ بصيغة PDF» من وجهة الطباعة |

### ملاحظة عن حفظ PDF
الحفظ يمرّ عبر نافذة الطباعة نفسها، وهذه **أضمن طريقة** تحفظ العربية بشكل سليم
بدون أي مكتبة خارجية. في نافذة الطباعة اختر الوجهة: **«حفظ بصيغة PDF»**.
اسم الملف يُقترح تلقائيًا مثل: `كشف-أحمد_سعيد-00012`.

### إعدادات الطباعة الموصى بها
- **A4**: المقاس A4، الهوامش افتراضية، فعّل **«الرسوم والخلفيات»** لتظهر الخطوط الفاصلة.
- **80mm**: اختر طابعتك الحرارية، والمقاس `80mm` أو `Roll`. الطول تلقائي حسب عدد الحركات.

## مزايا إضافية

- **بحث فوري** بالاسم أو الرقم — أو اضغط `/` للانتقال لحقل البحث.
- **تصفية**: الكل / عليه دين / مساوى. **ترتيب**: الأعلى دينًا / الأحدث / الاسم.
- **ملخّص علوي**: إجمالي الديون، عدد المدينين، إجمالي المسدَّد، إجمالي المسامحة.
- **📲 إرسال واتساب**: يرسل كشف الحساب للزبون كرسالة جاهزة.
- **تراجع** عن حذف أي حركة خلال ثوانٍ.
- **مظهر داكن / فاتح / تلقائي** عبر زر 🌙.
- **اختصار `n`** لإضافة شخص جديد.

## النسخ الاحتياطي ⚠️ مهم

البيانات محفوظة داخل المتصفح على جهازك (`localStorage`) — أي أنها **تُمسح لو نظّفت
بيانات المتصفح**. لذلك:

> من زر **⋯** ← **«تصدير نسخة احتياطية»** يحفظ ملف `JSON` فيه كل البيانات.
> ننصح بعملها كل فترة، وحفظ الملف في مكان آمن.

للاسترجاع: **⋯** ← **«استيراد نسخة»**، ثم اختر:
- **دمج**: يضيف الناقص ويُبقي بياناتك الحالية.
- **استبدال**: يمسح الحالي ويضع محتوى الملف مكانه.

كذلك من **⋯** ← **«بيانات المحل»** تغيّر الاسم والعنوان والهاتف والعملة —
وتظهر مباشرة في ترويسة كل فاتورة.

## هيكل الملفات

```
debts/
├── index.html              الصفحة الوحيدة
├── README.md               هذا الملف
└── assets/
    ├── css/
    │   ├── tokens.css      الألوان والمسافات والخطوط (الوضعان الداكن والفاتح)
    │   ├── glass.css       مادة Liquid Glass: الشفافية واللمعة والخلفية الحيّة
    │   ├── app.css         تخطيط الواجهة ومكوّناتها
    │   └── print.css       تنسيق الطباعة: A4 و80mm
    └── js/
        ├── spring.js       محرّك الحركة (نوابض قابلة للمقاطعة + إسقاط الزخم)
        ├── format.js       تنسيق المبالغ والتواريخ والنصوص
        ├── store.js        البيانات والحفظ والحسابات
        ├── invoice.js      بناء الفواتير والطباعة وحفظ PDF
        ├── ui.js           البطاقات وشاشة التفاصيل والنماذج
        └── app.js          التشغيل والبيانات التجريبية
```

**بدون أي مكتبة خارجية** — لا إنترنت، ولا `npm`، ولا خادم.
كل الملفات نصية عادية يمكنك فتحها وتعديلها بأي محرّر.

## كيف يُحسب الرصيد

```
الرصيد = مجموع الديون − (المسدَّد + المُسامح به)
```

- **موجب** → عليه دين (أحمر)
- **صفر** → مساوى ✓ (أخضر)
- **سالب** → له رصيد زائد، أي دفع أكثر من المطلوب (أزرق)

المسامحة **لا تحذف** أي حركة سابقة — تُسجَّل كحركة مستقلة، فيبقى السجل كاملًا للمراجعة.
