# وظائف Supabase — مكتب سفيان للموبايل

هذا المجلد يحتوي شيفرة الدوال الطرفية (Edge Functions) المنشورة على مشروع
Supabase `tyfidwamnlraysqrfdgb`. قبل هذا الإصدار كانت الشيفرة موجودة على
Supabase فقط بلا نسخة في المستودع.

| الدالة | المسار الحيّ | من يستدعيها |
|---|---|---|
| `docgen` | `/functions/v1/docgen` | البوت عبر `pg_net`، والـ Mini App |
| `miniapp` | `/functions/v1/miniapp` و `/miniapp/data` | واجهة الـ Mini App داخل تلغرام |

---

## 1) الفواتير: الأحرف الناقصة والأرقام المعكوسة

### السبب الأول — الأحرف الناقصة

كانت `docgen` تجلب خط Cairo من واجهة `fonts.googleapis.com/css2` بترويسة
`User-Agent` حديثة. Google في هذه الحالة يعيد ملفات **woff2** (مضغوطة Brotli)،
وهي غير صالحة لا لـ fontkit ولا لمواصفة PDF. سجلّ الدالة كان يوثّق ذلك حرفياً:

```
statement error: Error: Unknown font format
Error: font fetch failed: 404
no ttf url in google fonts css: ... url(https://fonts.gstatic.com/l/font?kit=...)
```

**الحل** في `docgen/font.ts`: نطلب واجهة `css` (v1) القديمة بترويسة متصفّح قديم
لا يدعم woff، فيعيد Google ملف **TrueType** ثابتاً. ثم لا نثق بالنتيجة: نتحقّق
من بصمة sfnt، ونفحص فعلياً وجود رسوم للحروف العربية والأرقام اللاتينية معاً،
ومع الفشل ننتقل إلى ترويسة ثانية ثم إلى عائلة خط بديلة (Noto Kufi ثم Amiri).

### السبب الثاني — الأرقام المعكوسة

fontkit ينفّذ تشكيل العربية (وصل الحروف عبر GSUB) بشكل صحيح، لكنه **يعكس كامل
المقطع** إذا رصد فيه حرفاً عربياً واحداً، لأنه لا يطبّق خوارزمية BiDi
(UAX#9). لذلك:

```
"الرصيد 1,750,000 IQD"   ⟵ المطلوب
"DQI 000,057,1 ديصرلا"   ⟵ ما كان يُرسم فعلاً
```

**الحل** في `docgen/rtl.ts`: نطبّق UAX#9 بأنفسنا عبر `bidi-js`، نقسّم كل سطر
إلى مقاطع اتجاهية، نرتّبها بصرياً (القاعدة L2) مع عكس الأقواس المتناظرة
(القاعدة L4)، ثم نرسم كل مقطع على حدة. عندها يعكس fontkit المقاطع العربية
فقط — وهو السلوك الصحيح — وتبقى الأرقام والكلمات اللاتينية بترتيبها.

المبالغ السالبة تُغلَّف بعازل LTR (`U+2066 … U+2069`) حتى تبقى الإشارة يسار
الرقم: `-238,000` بدل `238,000-`.

### تحسينات مرافقة

- تخطيط جديد كامل: ترويسة، بطاقة معلومات، جدول مخطّط، صندوق مجاميع، شارة حالة.
- **تعدّد الصفحات**: النسخة السابقة كانت تتوقّف عند `y < 90` وتُسقط بقية
  الأسطر بصمت. الآن تُفتح صفحة جديدة وتتكرّر الترويسة ويظهر «صفحة 2 من 3».
- لفّ النصوص الطويلة على سطرين مع اختصار بالنقاط الثلاث.
- حذف أي محرف لا يملك الخط رسماً له بدل إظهار مربّعات فارغة.
- ملف Excel: الأرقام صارت **أرقاماً حقيقية** بتنسيق عملة بدل نصوص، مع تجميد
  الترويسة وفلتر تلقائي.
- أجور التوصيل تُعرض كمعلومة مستقلة لأنها مسجّلة خارج `total_amount`.

### التحقّق

```
GET /functions/v1/docgen/selftest              # يعيد PDF نموذجياً للمعاينة
GET /functions/v1/docgen/selftest?format=json  # يعيد اسم الخط وحجمه وحجم الملف
```

النموذج مختار عمداً ليغطّي ما كان ينكسر: أسماء عربية، أسماء منتجات مختلطة
(`سماعة بلوتوث JBL Tune 510`، `كيبل Type-C سريع 1م`)، أقواس، مبالغ كبيرة،
وأسطر طويلة تحتاج لفّاً.

```
deno test --allow-net supabase/functions/docgen/rtl_test.ts
```

الاختبار يقارن ما سيُرسم فعلاً بالمرجع القياسي `getReorderedString` من
`bidi-js`، على حالات معروفة وعلى آلاف السلاسل العشوائية المختلطة.

## 2) المساعد الذكي في الـ Mini App

### ما الذي كان ضعيفاً

النسخة السابقة كانت جولتين ثابتتين: «أعطني JSON فيه sql» ثم جولة صياغة.
ونتج عن ذلك:

- أي خطأ في الاستعلام ينتهي بخطأ 500 — بلا محاولة تصحيح.
- أي سؤال يحتاج خطوتين يفشل، لأن الاستعلام واحد فقط.
- النموذج لا يعرف **تاريخ اليوم**، فأسئلة «اليوم / هالشهر / الشهر الماضي» تخمين.
- المخطّط كان سطراً واحداً بلا معاني الأعمدة، فالاستعلامات تخطئ في
  `balance` و`paid_amount` و`invoice_items` (الذي لا يملك `created_at` أصلاً).
- لا يعرف الكلمات التي يرفضها حارس `ai_query` فيصطدم بها.

### ما الذي تغيّر

- **وكيل حقيقي باستدعاء الأدوات**: أداة `run_sql` يمكن استدعاؤها حتى 4 مرات
  لكل سؤال، وإذا رجع خطأ يُعاد نصّ الخطأ إلى النموذج ليصحّح استعلامه.
- **دعم ثلاث صيغ**: OpenAI ومتوافقوها، Anthropic، Gemini — مع **ارتداد
  تلقائي** إلى بروتوكول نصّي (كتلة ```` ```sql ````) إذا كان النموذج لا يدعم
  الأدوات، فلا يتعطّل المساعد مهما كان المزوّد.
- **تعليمات غنية**: مخطّط موثّق بمعاني كل عمود وتحذيراته، قواعد SQL بتوقيت
  بغداد، الكلمات المحجوبة في حارس الأمان، وأسلوب رد عراقي محدّد.
- **الوقت الآن** بتوقيت بغداد (تاريخ + يوم الأسبوع + ساعة) يُحقن مع كل سؤال.
- **لقطة حيّة** من `miniapp_snapshot` (مبيعات اليوم، الديون، النواقص، أكبر
  المدينين) تُحقن في التعليمات، فالأسئلة العامة تُجاب فوراً وبأرقام صحيحة
  بلا استعلام أصلاً.
- **حارس استعلام محلّي** يرفض قبل الوصول لقاعدة البيانات، ويشرح السبب بالعربية
  للنموذج ليصحّح.
- تطبيع السؤال: أرقام هندية ⇒ لاتينية، حذف التطويل، توحيد المسافات.
- سجلّ المحادثة صار 16 دوراً بدل 12، والأخطاء ترجع برسائل عربية مفهومة.

### التحقّق

```
POST /functions/v1/miniapp/health   # المزوّد والنموذج المفعّل حالياً (يحتاج initData)
POST /functions/v1/miniapp  {"q":"...", "debug":true}   # يُرجع الاستعلامات المنفّذة
deno test --allow-net supabase/functions/miniapp/agent_test.ts
```

### النموذج المستعمل

المزوّد والنموذج يُقرآن من الخزنة (`ai_provider` و`ai_model` و`ai_base_url`)،
والقيمة المضبوطة حالياً هي `openrouter` + `google/gemini-3.1-flash-lite`.
هذا أصغر نموذج في عائلته؛ للحصول على إجابات أقوى في التحليل يكفي تغيير السرّ
`ai_model` في الخزنة إلى نموذج أقوى — بلا أي تعديل على الشيفرة.

## النشر

```
supabase functions deploy docgen  --no-verify-jwt
supabase functions deploy miniapp --no-verify-jwt
```

الدالتان تصادقان الطلبات بنفسهما عبر توقيع `initData` من تلغرام (ولذلك
`--no-verify-jwt`)، و`docgen` تقبل أيضاً نداءً داخلياً من البوت بترويسة
`x-cron-secret`.
