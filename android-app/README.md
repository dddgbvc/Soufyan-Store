# ياقوت ERP — تطبيق أندرويد (Flutter + Dart)

تطبيق أصلي لمكتب سفيان للموبايل، يعمل على نفس خادم ياقوت ويب ونفس قاعدة بيانات Supabase ونفس الصلاحيات.

## الدخول
1. **حساب المحل:** بريد وكلمة مرور المالك، مرة واحدة على كل هاتف. يُحفظ مفتاح تفعيل في مخزن الهاتف الآمن (Android Keystore). كلمة المرور لا تُحفظ.
2. **رمز PIN:** يحدد الموظف وصلاحياته.
3. **القفل:** تلقائي بعد الخمول (5 أو 10 أو 15 أو 30 دقيقة)، وزر لتبديل الموظف.

## الأقسام
تظهر الأقسام حسب صلاحيات الموظف في قاعدة البيانات:
- **الرئيسية:** المبيعات، الربح، الخزنة، الديون، ومخطط 7 أيام.
- **المبيعات والفواتير:** مع تفاصيل الأصناف.
- **الديون والزبائن:** كشف حساب، إضافة دين، تسديد ومسامحة، زبون جديد، تذكير واتساب، واتصال مباشر.
- **الخزنة:** إيداع وسحب.
- **المخزون والنواقص.**
- **الصيانة:** التفاصيل، ونقل الحالة، وإبلاغ الزبون أن جهازه جاهز.
- **الإنترنت (ISP):** المشتركون، والانتهاء، والتذكير بالتجديد.
- **المرتجعات، والمصروفات (مع مصروف جديد)، والشحن.**
- **الموظفون، والجلسات.**
- **مركز الإشعارات:** الصندوق، وإدارة إشعارات الموظفين، والإشعار المخصص.
- **الإعدادات:** إشعارات الهاتف، وأنواع الإشعارات، وساعات الهدوء، والمظهر، والأمان.

## الإشعارات (بدون Firebase)
- عند التفعيل من الإعدادات، يسجّل الهاتف رمزاً سرياً للموظف. القاعدة تحفظ بصمته sha256 فقط في `web_push_subscriptions` بنقطة `native:`.
- **أثناء فتح التطبيق:** فحص كل دقيقة.
- **في الخلفية:** WorkManager كل 15 دقيقة تقريباً، وهو الحد الأدنى الذي يسمح به أندرويد. المسار المستعمل `POST /api/native/poll`.
- **المحتوى:** نفس محتوى صندوق الموظف (`web_notifications`)، بنفس التفضيلات والصلاحيات. خلال ساعات الهدوء تصل بدون صوت.
- **لإشعار فوري في الخلفية:** نحتاج Firebase Cloud Messaging. يتطلب مشروع Firebase وملف `google-services.json`.

## البناء
```sh
flutter pub get
flutter build apk --release --split-per-abi --target-platform android-arm64,android-arm \
  --dart-define=YQ_BASE_URL=https://<عنوان-موقع-ياقوت>
```
- **عنوان الخادم:** لا يُحفظ في Git. يُمرَّر وقت البناء، وإن لم يُمرَّر يسأل التطبيق عنه عند أول فتح.
- **مفتاح التوقيع:** `android/key.properties` مع ملف `.jks`، وكلاهما خارج Git. احتفظ بهما: كل تحديث لاحق يجب أن يوقَّع بنفس المفتاح، وإلا يرفض أندرويد التثبيت فوق النسخة القديمة.

```properties
storePassword=...
keyPassword=...
keyAlias=yaqoot
storeFile=/المسار/yaqoot-release.jks
```

- **متطلبات البناء:**
  - Flutter 3.47 أو أحدث.
  - Android SDK 37، مطلوب لـ flutter_local_notifications 23.
  - Java 17 أو أحدث.
